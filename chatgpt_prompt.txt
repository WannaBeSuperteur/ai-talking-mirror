다음 조건으로 AI 말하는 거울을 학습하기 위한 전체 PyTorch 코드를 짜줘.

[환경 설정]
 - Windows 10
 - Python 3.12+, PyTorch
 - 12GB GPU 1대 (gpu:0) 에서 실행
 - 로컬에서 동작

[핵심 AI 모델]
 - 2B 이상 3B 이하의 국내 회사에서 개발한 LLM (거대 언어 모델) (Kanana 시리즈 등)
   - 해당 모델을 아주 발랄한 여성형 '말하는 거울'의 화법에 맞춘 500개 정도의 질문-답변 데이터셋 기반으로 SFT (Supervised Fine-Tuning)
     - 질문 형태: "[감정 분류 텍스트] {질문 내용}" (예: "[즐거움] 나 오늘 스타트업 머신러닝 엔지니어 면접 합격했어!")
     - 질문 구성: LLM이 최대한 다양한 상황을 학습할 수 있도록, 다양한 일상의 상황을 포함하여 텍스트 데이터의 구성을 최대한 다양하게 한다. (이모지 미 포함)
     - 답변 형태: "[표정]" {답변 내용}" (예: "[기쁨] 정말 축하해! 🎉 이제 너의 역량을 회사에서 발휘해 봐! 😊")
     - 답변 구성: 마찬가지로 다양한 일상의 상황을 포함하여, 질문에 맞는 텍스트 데이터의 구성을 최대한 다양하게 한다. (이모지 포함)
   - LoRA (Low-Rank Adaption) 적용
   - BF16, 4-bit quantization 사용
 - 카메라 화면을 통해 사용자 얼굴을 인식하고, 표정을 분석하는 기 학습 (Fine-tuning) 된 Vision 이미지 분류 모델 (5가지 감정 상태)

[핵심 AI 파이프라인]
 - Vision 이미지 분류 모델로부터 생성된 감정 분류 텍스트 (예: 기쁨, 즐거움, 슬픔, 화남) 을 LLM에 입력
 - LLM은 {감정 분류 텍스트} 를 포함한 질문을 입력하고, 답변을 생성

[추가 요구사항]
 - 말하는 거울 형태의 인터페이스 (가로 400px, 세로 600px 정도의 거울 안에, 카메라가 인식하는 사용자의 얼굴이 들어가는 새 창)
 - 재현 가능하도록 딥러닝 학습 시 모든 seed 고정
 - AI 말하는 거울의 답변 생성 시, 답변 내용을 자연스러운 TTS로 여성 목소리로 변환하여 출력하도록 함
   - 답변 내용 중 이모지는 제외한 내용을 TTS에 입력한다.
 - 말하는 거울의 표정 (인터페이스 창 정중앙에 이미지 형태로 표시) 을 말하는 거울의 답변에 포함된 [표정] 정보에 따라 표시한다.
   - 이때 각 표정 별 해당 표정이 그려진 이미지를 각각 생성하여 해당 이미지를 표시한다.
 - 필요한 Python 버전, 라이브러리 등이 포함된 pyproject.toml 을 반드시 포함한다. (uv sync 로 재현 가능하게)

명시되지 않은 요구사항은 자율적으로 결정한다.

거울 이미지에서 거울 테두리 안쪽 중 머리카락, 이목구비(표정) 를 제외한 나머지 부분을 반투명~투명 등으로 만들어서, 사용자의 얼굴이 거울 안에 표시되게 해줘. (거울 바깥쪽을 #FFFFFF 로 불투명하게 해줘.)
